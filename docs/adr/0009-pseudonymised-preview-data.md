# 9. Previews get synthetic or pseudonymised data, never a copy of production

- Status: accepted
- Date: 2026-10-28

## Context

A preview with an empty database tests very little, and a copy of production makes every preview a place where
personal data leaks. Previews are reachable by anyone who can reach the preview domain, live in namespaces
created on demand, and are seen by every reviewer of a pull request.

## Decision

- `Preview.DataSeeder` fills a preview's database when `seedData` is true, in one of two modes:
  - **synthetic** (default): a dataset generated by Bogus from a fixed seed, with known accounts the smoke and
    load tests use;
  - **pseudonymize**: a copy of a source database in which ids are derived with HMAC-SHA256 and a secret salt,
    names and emails are generated (emails under `example.invalid`), dates are shifted by a per-person offset of
    up to 45 days, and free text is replaced.
- Personal fields are marked `[PersonalData]` in the domain. A test fails when a marked field is not handled by
  the pseudonymiser, so adding personal data forces a decision about it.

## Consequences

- No real personal data ever reaches a preview. The pseudonymised mode keeps the shapes, volumes and
  relationships of real data, for bugs that synthetic data does not trigger.
- Pseudonymised data is still personal data under the GDPR (recital 26): whoever has the salt could rebuild
  the mapping. The salt lives in a Secret that previews cannot read.
- Shifted dates break nothing in this domain (durations and overlaps are preserved), but would break a domain
  where absolute dates matter, such as public holidays. The shift has to be revisited if that changes.

## Alternatives considered

- **Production snapshot with masked columns.** Masking in SQL is easy to get wrong silently, a forgotten
  column for example, and the snapshot still leaves production in full before it is masked.
- **Synthetic data only.** Safe and simple, the default here. It does not reproduce the data shapes that cause
  some production bugs.
